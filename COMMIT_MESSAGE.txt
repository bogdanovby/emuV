emuV v2.0: Auto GPU Detection + Automatic Spillover

Major release with automatic GPU detection and GPU → RAM spillover.

## New Features

- **Auto GPU Detection**: Automatically detects any NVIDIA GPU
  - No hardcoded models required
  - Dynamic PCI bus scanning
  - Automatic GPU information extraction

- **Automatic Spillover**: GPU → RAM priority system
  - GPU VRAM used first (Priority 1, ~7.5 GB)
  - System RAM overflow automatic (Priority 2, 10+ GB)
  - Transparent memory management
  - Total: 27+ GB available memory

- **Enhanced Monitoring**: Real-time statistics
  - GPU VRAM usage tracking
  - System RAM spillover tracking
  - Detailed sysfs interface
